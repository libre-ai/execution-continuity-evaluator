# Libre AI Execution Continuity Evaluator

[English](README.md)

Après une interruption, un workflow automatisé doit distinguer ce qui a été tenté de ce qui s’est réellement produit. Ce projet explore un évaluateur pour les développeurs de workflows pouvant reprendre. Il rapproche l’état enregistré des observations disponibles pour identifier une transition justifiée ou une décision encore ouverte.

## Usages visés

- Évaluer si une tâche interrompue peut reprendre depuis son état enregistré.
- Repérer des observations absentes ou contradictoires sur le résultat d’une opération.
- Examiner une entrée répétée avant de décider si un travail doit être retenté.
